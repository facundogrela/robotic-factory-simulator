# Robotic Factory Simulator

The `simulator` folder contains the Eclipse project for TP1 and TP2.
The Git tag `tp2-complete` preserves the completed TP2 version.

In Eclipse, import `simulator` as an existing project. Run
`config/PersistenceServer.launch`, then `config/SimulatorApplication.launch`.
The server uses port 5050 and saves `.factory` files in the simulator folder.

The initial commit history was organized into exercise steps after implementation.
