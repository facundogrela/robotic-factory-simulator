# Robotic Factory Simulator

Java 17 project for the concurrent programming and remote persistence exercises.

To run in Eclipse:

1. Import this folder as an existing project.
2. Run `config/PersistenceServer.launch`.
3. Run `config/SimulatorApplication.launch`.
4. Use File > Save Canvas or Open Canvas.

The server uses `localhost:5050` and saves `.factory` files in the project folder.
Logging is configured in `config/logging.properties`.

The commit history was organized into exercise steps after implementation.
